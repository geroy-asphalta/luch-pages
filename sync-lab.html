1. Проверка доступа без VPN

Проверим доступность Firebase SDK и серверов Google. Успех не гарантирует доступность конкретного проекта.

2. Настройка Firebase

Используй только настройки Web app из Firebase Console (apiKey, authDomain, projectId, appId). Не вставляй пароль, приватный ключ или JSON сервисного аккаунта.

3. Проверка обмена

Зайди под одним тестовым аккаунтом с Mac и iPhone. Измени заметку на одном устройстве — второе увидит её автоматически.
